# Anforderungen

Dieses Verzeichnis ist die verbindliche Quelle für fachliche und technische Anforderungen. Jede Datei behandelt einen Themenbereich und nummeriert ihre Anforderungen fortlaufend. Stabile IDs erleichtern Verweise; die Nummern werden bei Änderungen nicht wiederverwendet.

Bei neuen oder geänderten Entscheidungen werden die betroffenen Anforderungen hier ergänzt oder angepasst. Bestehende Anforderungen dürfen nicht widersprüchlich erweitert werden: Konflikte werden vor der Umsetzung geklärt und die Dokumentation entsprechend bereinigt.
